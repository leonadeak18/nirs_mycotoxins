# Model Population Analysis to Optimize Near-Infrared-Based Screening of Deoxynivalenol in Wheat

This repository contains the official code and data structure for the research paper: 
> **"Model Population Analysis to Optimize Near-Infrared-Based Screening of Deoxynivalenol in Wheat"**

---

## Repository Structure

The project is organized into the following directories to ensure reproducibility and ease of navigation:

| Directory | Description |
| :--- | :--- |
| `Data/` | Contains all raw intact and ground Near-Infrared Spectroscopy (NIRS) spectra, corresponding reference values, and data splitting configurations. |
| `Figures/` | Stores the output plots and visualizations generated by the pipeline. |
| `Model/` | Contains the core execution code and scripts required to run the analysis pipeline. |
| `Results/` | Holds the output model calculations, performance metrics, and evaluation data. |
| `Utils/` | Includes utility scripts and helper functions used for plotting and modeling. |
